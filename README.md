# เที่ยวอุทยานไทย

Dashboard วิเคราะห์จำนวนนักท่องเที่ยวในอุทยานแห่งชาติ ปีงบประมาณ 2567 (ตุลาคม 2566–กันยายน 2567) ด้วย Python, Pandas, Streamlit และ Plotly

## แหล่งข้อมูล

- [ข้อมูลนักท่องเที่ยวในอุทยานแห่งชาติ — data.go.th](https://data.go.th/th/dataset/gdpublish-stat-tourism)
- หน่วยงาน: กรมอุทยานแห่งชาติ สัตว์ป่า และพันธุ์พืช
- [ไฟล์ต้นทาง tourism67.xlsx](https://catalog.dnp.go.th/dataset/91d66c6a-5b88-41ee-8597-11be8aec5aa6/resource/654cbf2f-0bcf-4650-9b82-4207f869e09c/download/tourism67.xlsx)
- ปรับปรุงไฟล์: 2 ธันวาคม 2567
- สัญญาอนุญาตตาม metadata: Open Data Common

ข้อมูล 156 อุทยาน × 12 เดือน รวม 1,872 รายการ จำนวนรวม 18,637,467 คน ตามไฟล์ต้นทาง แปลงจากตารางแบบกว้างเป็นรายอุทยาน–เดือนโดยไม่เติมหรือสร้างตัวเลข ค่าศูนย์คงไว้ตามต้นทาง ไม่ตีความเป็นจำนวนบุคคลไม่ซ้ำ และไม่ตีความว่าทุกอุทยานเปิดให้บริการตลอดปี

## การใช้งาน

เลือกสังกัด อุทยาน เดือน และจำนวนอันดับที่ต้องการดู ดูกราฟแนวโน้มรายเดือน กราฟแท่งอันดับอุทยาน และแผนภาพความร้อนรายเดือน พร้อมตารางและดาวน์โหลด CSV ตามตัวกรอง ช่องสังกัดและอุทยานที่ว่างหมายถึงทั้งหมด ส่วนเดือนต้องเลือกอย่างน้อยหนึ่งเดือน

## รันบนเครื่อง

```bash
pip install -r requirements.txt
streamlit run app.py
```
